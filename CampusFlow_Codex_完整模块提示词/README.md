# CampusFlow 全功能 Codex 提示词包

**目标**：大学生跨平台智能课程表，Web/PWA + Android APK + Windows EXE；iOS/macOS 保留工程与后续原生构建路径。

**本次按照你的选择包含 18 个大模块，累计 398 个细分功能**，按此前清单原样保留模块编号。没有选择的 **09 课程笔记与学习资料**、**10 校园地图与教室导航** 不在此包内。

## 推荐用法

1. 将 ZIP 解压到单独目录，先打开 `00_Codex_总控提示词.md`。
2. 把 `00_Codex_总控提示词.md` 提供给 Codex，并允许 Codex 阅读包内共享架构和对应模块文件。
3. **如果当前尚无仓库**：先执行“阶段 0”，再执行 `modules/01_...`。
4. **如果已有仓库**：让 Codex 先检查仓库，禁止覆盖现有功能和用户数据。
5. 每次执行一个模块的一个批次，跑完测试再让 Codex 继续。
6. 不想逐文件粘贴时，使用 `CampusFlow_全部模块开发提示词_单文件合集.md`（文件比较长）。

## 技术决策及真实限制

- React + TypeScript + Vite + Tailwind CSS + Zustand；IndexedDB/Dexie 持久化，必要时按平台扩展 SQLite；Capacitor / Tauri 2 负责平台封装。
- **离线优先 ≠ 自动同步**。Google/Outlook/飞书/CalDAV、WebDAV、多人协作需要接入真实授权接口和（某些场景）后端服务，建议后期实施。
- **原生 Widget 不等于网页组件**。Android App Widget、iOS WidgetKit、Windows 托盘/悬浮窗口要用对应原生能力实现与测试。
- 在 Windows 可以开发/构建 Web、Android 和 Windows；**iOS/macOS 原生构建与签名通常需要 macOS + Xcode**。
- AI 可由用户自行配置服务商/密钥，但输出一律经 JSON schema 校验和用户确认，不能自动覆盖课表；涉及服务端代理和浏览器 Key 安全需独立设计。
- 不加入两个未选的模块，但其他已选模块里“课程地点文本”“作业任务”“个人日程”维持各自要求。
