# CampusFlow / 模块 03：课表导入与导出 —— Codex 可执行开发提示词

> 使用方法：将此文件的全部内容直接粘贴给 Codex；或让 Codex 在仓库中读取此文件并按步骤执行。
>
> 本文件是 **独立可执行** 的模块提示词。预计覆盖 **25 项子功能**。如果开发环境不允许一次完成，按照“分批任务”逐批实施；每批必须可运行、可验证。

## 本模块目标

实现可审计、可撤回的导入流水线与可靠导出，降低大学生录入课程成本。

**前置依赖**：依赖 01 数据约束；图片/AI 导入对接 13 可选解析器。

**建议数据实体/接口**：`ImportJob`, `ImportSource`, `ImportPreview`, `FieldMapping`, `ImportIssue`, `ExportJob`, `BackupManifest`。

**跨端特殊约束**：选择文件/分享文件由平台文件适配器处理；权限可拒绝；PDF/图片解析按实际依赖可用性分层。

## A. 开始前必须遵守的共同规则

你是资深全栈工程师、React/TypeScript 架构师、跨平台工程师与测试工程师。请直接在当前仓库中执行以下任务；如仓库为空，则先建立可运行项目。

1. **先检查**：目录、依赖、git 状态、运行脚本、数据模型、已有功能和测试；如用户已有实现，以实际仓库为准，先做兼容性分析。
2. **保持不破坏**：严禁为了实现本模块重写整个项目、删除无关模块、清空 IndexedDB、静默改变已有持久化字段或破坏旧备份。所有 schema 变更使用版本化迁移与回滚/恢复策略。
3. **共享核心**：React + TypeScript + Vite + Tailwind CSS + shadcn/ui + Zustand + Dexie/IndexedDB；使用 Capacitor 为 Android/iOS 提供原生壳，使用 Tauri 2 为 Windows/macOS 提供桌面壳。保留可扩展适配器，优先复用 UI、业务规则、验证与测试。技术可依据现有仓库适配，不得无理由换栈。
4. **离线优先**：没有互联网和账号也能使用核心课表；跨设备自动同步、共享权限、短链、在线协作等需要真实授权服务时，必须清楚拆成后续可选层，不得伪造成功结果。
5. **平台真实能力**：通过 `PlatformCapabilities` 检测权限/特性；不支持时隐藏或禁用按钮并说明原因。iOS/macOS 原生构建需 macOS/Xcode，不得在 Windows 假装产出了已签名的安装包。
6. **隐私优先**：采用最小数据原则，导出、分享、截图与日志默认保护个人课程、教室、座位、备注。不得把用户 API Key、OAuth Token、凭据打包到 Web 静态代码、同步数据或明文日志中。
7. **交互完整**：界面控件必须有可运行的动作；有加载/错误/空状态、取消和撤销入口；中文为默认语言，兼容英文；支持触摸、键盘、屏幕阅读器及减少动画。
8. **保守执行**：遇到依赖缺失或平台 API 不可用，优先实现可运行的接口、单元测试和明确标注的功能降级；不要用假数据冒充正式结果，不要用不存在的 SDK/API。
9. **先测试再汇报**：完成后执行当前环境可用的 lint、typecheck、unit、build 和相关端到端测试。未执行的检查如实列明原因。
10. **阶段提交**：只完成本模块，不要顺带实现其他大模块；输出更改文件、迁移影响、测试结果、已知限制及下一阶段建议。

## B. 完整功能清单与逐项实现指令（25 项）

下面每一行均是**必须实际实现的子功能**，不能仅作为 backlog 或展示占位。按依赖拆成若干批，重要功能先构建可使用路径。

| 编号 | 子功能 | Codex 必须完成的实施细则 |
|---:|---|---|
| 1 | **手动录入** | 复用 01 课程编辑器并支持多上课时间和批量保存。 |
| 2 | **Excel 文件导入** | 解析 XLSX 多工作表、合并单元格和中文列名，预览字段匹配。 |
| 3 | **CSV 文件导入** | 支持 UTF-8 BOM、常用分隔符和换行转义，标记编码异常。 |
| 4 | **ICS 日历文件导入** | 解析事件、时区、重复规则与例外；无法表达节次时转换为具体时刻。 |
| 5 | **JSON 备份导入** | 校验文件版本、结构与校验和，支持整库与选择性恢复。 |
| 6 | **PDF 课表解析** | 优先提取可选中文本/表格，扫描件转 OCR 的结果须人工核对。 |
| 7 | **课程表截图识别** | 对齐课程格、星期、节次、周次，由识别适配器输出结构化候选。 |
| 8 | **手机拍照识别课表** | 选择相机或照片，处理旋转、裁剪与模糊反馈，再走预览。 |
| 9 | **AI 识别课程名称与时间** | 采用结构化 JSON 输出并严格校验，低置信字段高亮。 |
| 10 | **复制粘贴文本智能识别** | 支持多行粘贴并解析周次/单双周/教室，未识别项标明。 |
| 11 | **批量导入课程** | 按学期、课表 profile 成批导入，使用数据库事务避免半导入。 |
| 12 | **导入前预览** | 预览原始字段与规范化课程，允许编辑后才写入数据库。 |
| 13 | **导入冲突检测** | 提前列出时间交叠、学期不符、异常周次及修复建议。 |
| 14 | **导入重复课程检测** | 按名称、时间、教室与周规则计算候选重复，允许逐项选择。 |
| 15 | **导入字段手动映射** | 用映射面板将学校列名匹配统一字段，保存可复用映射。 |
| 16 | **学校教务系统导出文件适配** | 按学校文件格式注册解析器；只处理用户提供或授权的数据。 |
| 17 | **自定义导入模板** | 提供可下载 CSV/XLSX 模板与示例数据、字段说明。 |
| 18 | **导出课程表 PNG 图片** | 支持清晰度、主题、周次和隐私字段开关。 |
| 19 | **导出高清 PDF** | 支持 A4/横版分页、字体嵌入策略与长课表分页。 |
| 20 | **导出 Excel** | 字段齐全包含周次、单双周、多会话及 Unicode 内容。 |
| 21 | **导出 ICS 日历文件** | 将本地教学周解析为带时区事件；支持例外日期防止遗漏。 |
| 22 | **导出完整 JSON 数据** | 包含版本、校验信息与所有关联实体；机密凭据不导出。 |
| 23 | **课程表二维码分享** | 仅将短文本、小体积脱敏数据写入二维码；大数据用文件/安全链接。 |
| 24 | **导入历史记录** | 保留来源、时间、数量、失败原因及可撤销批次 ID。 |
| 25 | **导入错误定位及修复** | 定位到具体文件行、单元格或字段，并在界面快速修正。 |


## C. 实施方式（不是只写静态页面）

**先提交变更计划，再开始写代码**，计划列出受影响的 package、表/迁移、TypeScript 类型、服务/仓储接口、页面路由、平台适配和测试。执行时遵循以下顺序：

- **领域层**：将业务规则放在纯函数/服务中，不把日期算法、过滤规则或同步冲突散落在 React 组件中；所有实体具备稳定 ID、创建/更新时间、schemaVersion（适用时）和校验规则。
- **数据层**：通过 `Repository` 和版本化 Dexie schema 持久化；写入事务、引用校验、备份兼容、异常回滚、离线恢复。
- **交互层**：提供至少一条完成目标的完整操作路径，适配手机单列/底部导航与桌面侧栏/快捷键；重要操作有可见结果及撤销/确认。
- **平台层**：统一适配器返回支持状态、权限状态、执行结果和错误原因；对原生专属特性独立开发并提供可验证的安装/调试说明。
- **测试层**：对纯业务规则写单元测试，对用户主要路径写集成/E2E，对导入/同步/通知等异常场景写回归测试。
- **文档层**：同步更新 `README.md`、`docs/ARCHITECTURE.md`、`docs/FEATURES.md` 和 `docs/CHANGELOG.md`（若文件不存在可新建）；记录 API/权限条件与手动测试步骤。

每项功能必须具备：**数据模型或既有模型映射 → 可用操作路径 → 正确状态展示 → 错误与空状态 → 至少一项验收检查**。若功能需外部授权/服务器/原生扩展，请在代码和说明中区分“已实装”“受平台限制”“等待配置”，不可留下一个假成功按钮。
