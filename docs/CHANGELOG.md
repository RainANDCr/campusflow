- **自动定期本地备份**（17 #4）：每 24 小时快照，本机保留最近 3 份，设置页一键恢复。

### 模块 02 课表显示与交互（第 1-2 批）

- **月历视图**：月格显示课程密度圆点 + 考试（△）/日程标记，点击某天跳到该天日视图（跨周/跨月正确换算教学周）。
- **时间轴视图**：按真实时刻排布课程块，小时刻度 + 当前时刻红线，体现不等长课程与空闲区间。

- **明日课程预览**：课表页倒计时卡下方显示明日课程摘要（正确处理跨周/跨学期边界）。

### 模块 01 课程表核心功能（第 1-5 批已完成，25/25 验收）

- **数据模型 v2**（Dexie schema 2，自动迁移）：新增 `timetableProfiles` 表（多套课表方案）；课程新增 `tags`（自由标签）、`classGroup`（教学班）、`profileId`（方案归属）。v1 数据自动升级：每个学期创建「主课表」方案并回填归属；旧备份导入后自动补齐。
- **时间感知冲突检测**（`core/services/conflictTime.ts`）：把重复规则展开为具体日期+实际时刻（按该天有效作息解析），半开区间 `[start, end)` 判定——相邻课程（上一节结束=下一节开始）不再误报冲突；课程表单的保存前冲突警告已切换到该引擎。
- **按日专属作息**：节次可标记「仅周X」，某天存在专属节次时整日替换通用作息；网格中未覆盖的节次行置灰禁用；日视图/课次时间解析全部按有效作息计算。
- **课间休息**：由相邻节次时间间隔推导（无独立实体），周课表时间列展示「课间X′」。
- **多套课表**：学期页可创建/激活/设主/删除方案；课表数据按激活方案隔离；课程表单可选择归属方案。
- **删除撤销**：课程删除、批量删除、学期级联删除均生成快照，底部撤销条 8 秒内可一键恢复（事务化快照恢复）。
- **搜索筛选**：课程管理支持按名称/教师/教室/教学班/标签搜索与标签筛选；列表展示标签与教学班。
- **历史学期查询**：学期页「查看历史课程」只读视图，支持按课程名/教师/教室/标签/教学班搜索。
