# CampusFlow UI 设计规范

## 1. 设计方向

**现代极简 + 文艺清新 + 轻二次元点缀。** 对标现代日历应用的信息密度与易用性，配色和氛围更年轻。原则：

1. 课表是主角：装饰一律低饱和、低透明度，永不干扰课程阅读。
2. 一屏一个重点；次级信息用 `muted-foreground` 弱化。
3. 装饰默认关闭（`decorations: false`），用户可一键开启/关闭。
4. 动效服务于空间感与状态反馈，单个过渡 ≤ 250ms，绝不拖慢操作。

## 2. 主题系统（已实现，`src/theme/theme.css`）

- **6 主题 × 2 模式**：奶油白（默认）、樱花粉、天空蓝、森林绿、深夜星空、极简黑白；每个主题都有浅色与深色两套完整变量。
- **显示模式**：跟随系统 / 浅色 / 深色（`matchMedia` 监听实时响应）。
- **8 强调色**：琥珀、玫红、钴蓝（默认）、青绿、堇紫、橘橙、湖蓝、桃粉；用于当前指示、进度、装饰光晕。高亮度强调色（琥珀/青绿/湖蓝）自动使用深色前景保证对比度。
- **实现**：`data-theme` + `.dark` + `data-accent` 三个根属性切换 CSS 变量；Tailwind 4 `@theme inline` 映射为 `bg-background`、`text-foreground` 等工具类。切换即时生效，刷新由 localStorage 启动缓存防闪烁。
- 可读性底线：正文/背景对比度 ≥ 4.5:1，弱化文本 ≥ 3:1；深色模式不是简单反色，逐主题调校。

## 3. 布局规范（已实现骨架）

### 移动端（< md）
- 底部导航 4 项：课表 / 日程 / 学期 / 设置；触控目标 ≥ 44px；`env(safe-area-inset-bottom)` 适配。
- 内容区单列，页面级左右留白 16px；支持纵向滚动。
- 课程网格：时间列 + 周末可隐藏（`showWeekend` 设置）；支持手势切周（第二阶段）。

### 桌面端（≥ md）
- 左侧 224px 导航栏（`bg-card/60`），内容最大宽 1152px 居中。
- 第三阶段起：课程详情用右侧侧边栏而非弹窗；支持右键菜单与快捷键。

### 通用
- 圆角：卡片 `rounded-2xl`，按钮/输入 `rounded-xl`，标签全圆。
- 层级：内容卡片（`border + shadow-sm`）→ 弹层（后续用 backdrop-blur）。
- 空状态：统一 `EmptyState` 组件（图标 + 标题 + 说明 + 操作）。

## 4. 动效规范（Framer Motion）

| 场景 | 规格 |
| --- | --- |
| 页面切换 | fade + 上移 10px，220ms easeOut（已实现） |
| 切周（第二阶段） | 水平滑动 + 方向感，240ms |
| 卡片入场 | 轻微 scale 0.97→1 + fade，stagger 20ms |
| 弹窗 | fade + scale 0.98→1，180ms |
| 按钮反馈 | `active:scale-[0.98]` + hover 透明度（已实现） |
| 主题切换 | 背景/文字 250ms 过渡（已实现） |

- 全局 `MotionConfig reducedMotion="user"` + CSS `prefers-reduced-motion` 兜底，系统减弱动效时全部动画趋近于零。
- 轻二次元装饰（可开关）：第一阶段为极淡强调色光晕；第六阶段加入樱花/落叶/星空粒子（Canvas 实现，不影响主线程）。

## 5. 课程配色方案（第二阶段落地）

12 色低饱和课程色板（ID 存 `Course.color`，CSS 变量实现，随主题明暗自动适配）：
玫瑰、珊瑚、琥珀、柠檬、青柠、薄荷、青绿、天蓝、鸢尾、紫藤、藕荷、石墨。
每色输出三档：`-soft`（卡底）、`-solid`（主色）、`-text`（可读文字色）。

## 6. 无障碍

- 交互元素全部语义化（button/link/switch + aria-pressed/aria-checked）。
- 颜色不是唯一信息载体：课程类型/状态同时用文字或图标表达。
- 焦点可见：全局 `focus-visible:ring-2 ring-ring`。
- 触控目标 ≥ 44×44px；小屏不出现横向溢出（网格允许横向滚动作为兜底）。
