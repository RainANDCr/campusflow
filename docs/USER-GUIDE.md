# CampusFlow 超详细使用手册

> **适用人群**：完全不懂技术的同学。本手册逐一介绍 CampusFlow 的**每一个功能**，包括它在哪、怎么用、每个选项是什么意思、用了会发生什么。
> 阅读方式：不必从头读到尾——第一章看完就能上手，之后哪里不懂查哪里。文末附名词小词典与 FAQ。

---

## 第一章 获取与安装

CampusFlow 有三种获取方式，功能完全相同，数据各自独立保存在对应设备里。

### 1.1 浏览器直接使用（零安装）

用任何现代浏览器（Chrome、Edge、Safari、Firefox 均可）打开：

**https://rainandcr.github.io/campusflow/**

页面打开即可使用。建议把网址加入书签。这是最快上手的方式，也是其他一切方式的基础。

### 1.2 安装为 PWA 应用（手机 / 电脑都可，推荐）

PWA = 让网页变成一个"像 App 一样"的存在：有自己的图标、全屏界面、断网也能看课表。

**安卓手机（Chrome 或 Edge）：**
1. 用浏览器打开上面的网址；
2. 点浏览器右上角「⋮」菜单；
3. 点「添加到主屏幕」或「安装应用」；
4. 确认后，桌面上出现 CampusFlow 图标。以后从图标打开，没有地址栏，像原生 App。

**iPhone（必须用 Safari）：**
1. Safari 打开网址；
2. 点底部中央「分享」按钮（方框加向上箭头）；
3. 列表往下拉，点「添加到主屏幕」→「添加」。

**Windows / macOS 电脑（Chrome 或 Edge）：**
- 地址栏右侧会出现一个「安装」小图标（显示器加箭头），点击 →「安装」；
- 或菜单（⋮）→「投放、保存和分享」→「安装页面为应用」。
- 安装后从开始菜单/启动台打开，独立窗口运行。

### 1.3 Windows 安装包（提醒功能最可靠）

1. 打开发布页：https://github.com/RainANDCr/campusflow/releases
2. 在最新 Release 的 Assets 里下载 `CampusFlow_x64-setup.exe`；
3. 双击运行。Windows 可能弹出蓝色SmartScreen警告（因程序无付费数字签名），点「更多信息」→「仍要运行」；
4. 按提示完成安装。开始菜单、桌面会出现图标；系统托盘（屏幕右下角）也有一个小图标，右键可「显示课表」或「退出」。
5. 如果想在开机时自动启动：安装版支持自启功能，可在 Windows 设置 → 应用 → 启动 中管理。

### 1.4 该选哪种？

| 场景 | 建议 |
| --- | --- |
| 先随便试试 | 浏览器直接打开 |
| 手机日常使用 | PWA 安装到主屏幕 |
| 想要最可靠的上课提醒 | Windows 安装包 |
| 想看源码 / 参与开发 | GitHub 仓库 clone |

## 第二章 首次启动与新手引导

第一次打开（且还没有任何学期）时，会自动弹出**三步引导**：

1. **欢迎使用**：一句话介绍软件定位与原则（数据本地、离线可用）；
2. **第一步：创建学期**：告诉你去哪里建学期。若已建过会提示"可跳过此步"；点「前往学期页」直接跳转；
3. **第二步：添加课程**：介绍两种建课方式（手动与导入）。

- 点「下一步」逐页看，点「跳过」直接关闭；
- 关闭后**不会再出现**（系统记住了）；想再看？清空数据重新开始即可（见 14.5）。

## 第三章 学期管理（「学期」页）

学期是 CampusFlow 的一等公民：**课程、节次时间、调课记录、考试、日程都挂在学期下面**。换学期 = 换一整套课表。

### 3.1 创建学期

点「学期」页 → 右上角「创建学期」，逐字段说明：

| 字段 | 填什么 | 说明 |
| --- | --- | --- |
| 学期名称 | 如 `2026-2027学年第一学期` | 必填，只用于显示 |
| 开学日期 | 如 2026-09-01 | 必填。用于判定"是否开学/假期" |
| 教学周数 | 如 20 | 必填。1～40。决定第几周到第几周 |
| 每周起始日 | 周一（默认）或周日 | 影响课表列顺序与周的分界。国内高校基本选周一 |
| 第一周起始日期 | 自动填好 | **重点字段**。默认 = 开学日期所在周的第一天。例：9月1日周二开学 → 自动填 8月31日周一。这一天的所在周就是"第 1 周"，之后每 7 天是第 2、3 周……**单双周、指定周全部以它为基准**。如果学校校历的第一周和自动推算不一致，手动改它即可 |
| 节次时间 | 默认 12 节 | 详见第四章，可套用模板或自由修改 |
| 特殊教学周 | 空 | 给某些周打标签（考试周/实训周/假期周/自定义），课表页对应周会显示角标。点「添加」→ 填周数 → 选类型 → 可加备注 |

填完点「保存」。学期卡片上会显示：名称、「当前」徽标、进行中/归档状态、当前第几周（或未开学/假期中）、日期范围、周数、每周起始日、以及下方的**课表方案**一栏。

### 3.2 套用作息模板

创建/编辑学期时，节次时间区域右上有「套用作息模板…」下拉，内置三套：

- **常规 12 节**：8:00 起每两节一单元，19:00 后两节晚课（最常见）；
- **紧凑 8 节**：无午休连排（适合实训/短学期）；
- **含晚自习 14 节**：白天 10 节 + 晚上 4 节。

选一个即整体替换当前节次列表，之后仍可逐节微调。

### 3.3 编辑节次时间（自定义每节课的上下课时间）

节次编辑器每一行从左到右：

1. **适用星期**：默认「每天」。如果选了「仅周四」之类，那么**那一天将整体使用这些专属节次**（例如学校周四只上 6 节：把 6 行设为"仅周四"，周四就只有 6 节，课表上周四多余节次会置灰）；
2. **开始时间 / 结束时间**：点时间输入框修改；
3. **垃圾桶按钮**：删除该节（至少保留一节）；
4. **「添加一节」**：在末尾追加一节，起止时间自动接上一节。

课间休息不用单独设置：两节之间的时间差自动成为"课间"，显示在周视图时间列（如「课间10′」）。

### 3.4 编辑 / 归档 / 删除 / 切换学期

学期列表中每个学期卡片右侧有四个按钮：

- **📖 查看历史课程**：只读查看该学期全部课程与安排，支持按课程名/教师/教室/标签/教学班搜索。归档了的老学期靠这个回查；
- **✏️ 编辑学期**：修改所有信息（含节次时间、特殊教学周）。注意：改开学日期会连带影响所有教学周计算；
- **🗄 归档 / 恢复**：上学期结束了？点归档。归档学期保留全部数据、只读、不参与"当前学期"自动选择；想再改随时恢复；
- **🗑 删除**：删除学期及其**全部**从属数据（课程、安排、调课记录、节次、课表方案）。弹出二次确认；删除后屏幕底部出现 8 秒「撤销」条，点它能整体还原。

### 3.5 设为当前学期

学期卡片上的「设为当前」按钮（「当前」徽标的学期不显示）。课表页永远显示"当前学期"的内容。切换时课表视图自动重置回本周。

### 3.6 多套课表方案（同一学期）

每个学期卡片下方有「课表方案」一栏（图层图标）：

- **「＋新方案」**：输入名字（如"试听课表"）→ 确定。创建后自动切换到新方案（它是空的）；
- **点击方案名**：切换到该方案。课表页只显示当前方案下的课程；
- **★**：把该方案设为主课表（主方案是默认显示与新建课程的归属）；
- **×**：删除方案（主方案不能直接删；方案里的课程会回到主方案）。

典型用法：选课周建一个"备选方案"试排，确定后再切回主课表。

## 第四章 课程管理（「课表」页）

### 4.1 添加课程（完整字段说明）

点头部「添加课程」按钮（电脑）或右下角 ➕（手机）。逐项说明：

| 字段 | 说明 |
| --- | --- |
| 课程名称 | 必填，最长 80 字。课表卡片上显示的文字 |
| 课程类型 | 6 选 1：理论课 / 实验课 / 体育课 / 研讨课 / 选修课 / 网课。显示在详情页 |
| 教师（默认） | 这门课的任课教师。所有上课时间默认继承它 |
| 教学楼 / 教室（默认） | 上课地点。显示在卡片与详情页 |
| 所属课表方案 | 多方案时出现，选归到哪套课表 |
| 教学班 | 同一门课多个班时区分用，如「2026级1班」。显示在课程管理列表 |
| 标签 | 自由文字，逗号分隔，最多 10 个（如：必修，考研课）。用于搜索与筛选 |
| 上课提醒 | 默认"跟随全局设置"；也可单独设为不提醒 / 提前 5/10/15/30/60 分钟。**只影响这一门课** |
| 课程颜色 | 12 色色板：玫瑰/珊瑚/琥珀/柠黄/青柠/翠绿/青绿/天蓝/钴蓝/堇紫/品红/石墨 |
| 图标 | 16 个 emoji（📐🧪💻🎨🎵⚽🌍⚖️🩺📖🔬🗣️🎭🧠⭐🈯），显示在卡片与列表 |
| 备注 | 500 字以内纯文本（教材、考核方式等），详情页显示 |

### 4.2 上课时间（一个课程可以有任意多个安排）

「上课时间」区域每个卡片代表一条重复规则：

- **星期**：周一～周日；
- **起始节次 / 结束节次**：下拉里每个节次都带着开始时间（如「第3节 10:00」），选完就知道具体钟点。结束节次下拉只列出 ≥ 起始节次的选项，不会选反；
- **周次规则**：五种——
  - **每周上课**：所有教学周；
  - **单周**：第 1、3、5…周（教务系统写"单周"选它）；
  - **双周**：第 2、4、6…周；
  - **连续区间**：填起止周，如第 1～8 周、第 9～16 周；
  - **指定周次**：出现 1～N 的周数按钮墙，点哪几周亮哪几周（如 1、3、5、7）；
- **本时间教师 / 本时间教室**：留空 = 用课程默认；填了 = 只有这个时间的课用这个老师/教室。配合不同周次规则，就能实现"1-8 周在 A 楼张老师、9-16 周在 B 楼李老师"。

点「添加时间」加第二个、第三个安排；点垃圾桶删掉某个安排（至少留一个）。

保存前软件会做**冲突检测**：如果新安排与其他课程在某几周的同一天同一时段重叠，会列出冲突明细（如「高等数学（安排 1）」与「大学英语」：周一 第 1-2 节，20 个周次重叠）。确认确实要这样（比如两门课本来就不可能同时选）可以点「仍要保存」。

### 4.3 快速新建（点空白格）

周视图里每个空格子本身就是一个按钮，点它会打开添加课程表单，**星期和节次已经按你点的位置填好了**，只需要写课程名。这是日常最常用的建课方式。

### 4.4 编辑 / 复制 / 删除

- **编辑**：右键（电脑）或长按（手机）课程卡 →「编辑课程」；或点卡片进详情 →「编辑」。改完保存即可；
- **复制**：详情页「复制」按钮，整门课连安排复制为「××（副本）」，改个名字就是新课；
- **删除**：详情页「删除」→ 确认 → 底部弹 8 秒「撤销」条，点了立刻整体还原（含全部上课时间）。

### 4.5 课程管理弹窗（搜索与批量）

课表页点「课程管理」（列表图标）：

- **搜索框**：同时匹配课程名 / 教师 / 教室 / 教学班 / 标签；
- **标签下拉**：按标签一键筛选；
- **勾选多门**：底部出现操作条——12 个颜色圆点（批量改色）+「删除」（批量删除，需二次确认，支持撤销）；
- 每行铅笔图标进入该课编辑。

### 4.6 课程详情页

点任何课程卡打开。包含：彩色信息卡（名称/日期时间/地点/教师）、类型与节次徽标、**调课 / 停课 / 补课**三个入口、备注、该课程**全部上课安排**列表（当前这一次会标「本次」）、以及可点击复制的地点。

### 4.7 拖动调课（电脑端）

用鼠标**按住**课程卡拖动（超过 6 像素启动），跟随指针的虚线幽灵框显示「移至 周X 第N节」；松开后弹出**预填好的调课表单**（目标日期、节次自动算好并保留原时长，若与其它课冲突会给出黄色提示），确认后生效。它等价于一次"调课"：只影响这一次，不碰重复规则。想改每周的安排请用"编辑课程"。（触摸屏用长按菜单，拖拽为鼠标专用。）

## 第五章 课表显示（五种视图 + 全部细节）

### 5.1 周视图（默认）

横轴星期、纵轴节次。细节：

- **今天列**：整列淡色背景 + 表头高亮；
- **卡片颜色** = 课程颜色；同一时段重叠的课自动左右分栏并排；
- **状态**：正在上的课有强调色描边；已结束的变灰变淡；停课的划线；
- **角标**：「调」= 被调过；「补」= 补课；
- **「已调走」**占位：半透明虚线框，表示这节课被移去了别处；
- 跨节次的长课卡片自动跨行；卡片上显示图标、课名、@教室（大卡片还显示教师）；
- 点击空白格 = 快速建课；点击卡片 = 详情。

### 5.2 日视图

顶部一排星期按钮（今天标「·今」）切换查看日；列表按节次排序，每张卡显示起止时间、课名、地点、教师，进行中的课带「进行中」徽标。底部（如有）显示**「空闲时段」**：连续没课的节次区间，如「第 5-7 节」。再往下是**「当日个人日程」**：你在日程页建的日程自动叠加显示，与上课时间撞车会标「与课程时间重叠」。

### 5.3 月历视图

整月网格。有课的日子显示彩色小圆点（最多 4 个 + 溢出数字）；考试的日子有红色△和数量；日程有「程 N」标记；今天有描边。**点击任何一天直接跳到那天的日视图**（自动换算教学周）。左右箭头翻月。

### 5.4 时间轴视图

按真实钟点纵向排布：左侧小时刻度、课程块的高度与位置对应真实起止时间（能直观看到 2 节的课比 3 节的短）、当前时刻有一条红线（仅今天）。空档一目了然。

### 5.5 周列表视图

按星期折叠的精简列表：每天一行（显示课数），点开显示紧凑课程行（时间 + 课名 + 教室）。今天默认展开。适合快速浏览、小屏使用。

### 5.6 切周与定位（所有方式汇总）

- 箭头 ‹ › 逐周切换；
- 「回到本周」一键返回（假期中也会显示）；
- 手机左右滑动切周（日视图里左右滑切天）；
- 电脑 ← / → 切周，T 回本周；
- 「日期跳转」日期选择器：选任意日期，直接跳到它所在周的那一天并切到日视图。

### 5.7 显示控制（设置 → 外观）

- **卡片密度**：紧凑（44px 行高）/ 标准（56）/ 宽松（72）；
- **卡片显示教室 / 显示教师**：两个独立开关；
- **显示周末**：设置 → 外观里没有单独开关时，默认显示周六周日（数据不会丢）；
- **全屏**：课表页 ⛶ 按钮（浏览器不支持时按钮自动隐藏）。

## 第六章 调课、停课、补课与节假日（变更体系）

核心设计：**一切临时变更都是"例外记录"**，叠加在原始重复规则之上显示。原始规则永不改动，删除例外 = 完全恢复。

### 6.1 三种变更

| 类型 | 触发方式 | 效果 |
| --- | --- | --- |
| **停课** | 卡片右键/长按 →「停课（本次）」；或详情页「停课」 | 那一次课划线显示，不再提醒 |
| **调课** | 右键/长按 →「调课」；或详情页「调课」；或**拖拽卡片** | 改日期/节次/教室/教师（至少一项）。原时段显示「已调走」虚线占位，新位置出现「调」角标卡片 |
| **补课** | 详情页「补课」 | 在任意日期（含假期）新增一次课，带「补」角标 |

调课表单字段：原上课日期、调整后日期（与原日期相同 = 只改时间地点）、开始/结束节次、新教室、新教师、备注。修改会做冲突提示。

### 6.2 变更记录（可编辑、可撤销）

课表页「课程变更记录」（时钟图标）列出本学期所有变更（最新在前），每条显示类型徽标、课程、变更内容摘要、备注。操作：

- **✏️ 编辑**：重新打开表单修改这条变更；
- **🗑 撤销**：删除这条记录，课表该次立刻恢复原始安排。

### 6.3 节假日批量停课

课表页「节假日课程调整」（日历划叉图标）：

1. 选开始/结束日期（默认当前周）；
2. 填备注（如"国庆放假"）；
3. 自动预览范围内将被停掉的每一个课次（按周次规则与现有变更精确计算）；
4. 点「停课 N 个课次」一次性生成；可整批撤销（删除即恢复）。

### 6.4 特殊教学周

学期编辑里标注后（考试周/实训周/假期周/自定义），课表页标题旁在对应周显示红色角标（如「考试周」），一眼知道本周性质。

## 第七章 冲突检测（三种场景）

1. **添加/编辑课程保存时**：自动展开到具体日期与时间比对（相邻课程不算冲突），列出所有重叠明细；确认无误可「仍要保存」；
2. **导入预览时**：导入课程与现有课程之间的冲突全部列出（详见第十二章）；
3. **考试表单**：日期时间与另一场考试重叠时实时黄字提醒。

## 第八章 提醒系统（「设置 → 通知」）

### 8.1 开启通知（第一步，必做）

设置 → 通知 → 点「授权通知」。浏览器弹窗点**允许**。

- 之前点了拒绝？Chrome/Edge：地址栏左侧 🔒 → 通知 → 改为允许 → 刷新页面；
- Windows 安装版走系统通知，最可靠；网页版在浏览器运行期间可靠，浏览器完全关闭后不保证（技术限制，如实说明）。

### 8.2 五类提醒

| 提醒 | 开关 | 行为 |
| --- | --- | --- |
| 上课提醒 | 全局提前量（5/10/15/30/60 分钟） | 每节课前推送：课程、时间、教室、教师。**可被单门课程覆盖**（课程表单里的"上课提醒"） |
| 下课提醒 | 独立开关 | 每节课结束时推送 |
| 今日第一节课摘要 | 独立开关 | 第一节课前 1 小时："今日有 N 门课，第一节 …" |
| 考试提醒 | 恒开 | 考试前 30 分钟 |
| 待办截止提醒 | 恒开 | 截止日 8:00 提醒未完成待办；逾期的每天一次轻提醒 |

### 8.3 细粒度控制

- **通知静音时段**：设开始/结束（如 23:00–07:00，支持跨午夜）。落点在窗口内的提醒自动顺延到窗口结束；
- **周末课程提醒**：关闭后周六周日的课程不弹通知（课表照常显示）；
- 调课/补课的提醒标题自动带【已调整】【补课】前缀，正文含新教室与备注——换教室了第一时间知道。

## 第九章 日程、考试、待办（「日程」页）

### 9.1 日程（个人日程 / 临时活动 / 重要日期）

「日程」标签 →「添加日程」：

- 标题、日期、类别（个人日程/临时活动/重要日期/待办）、全天或起止时间、备注；
- **重复**：不重复 / 每周（社团例会）/ 每年（生日、纪念日，2 月 29 日也不丢）。重复日程在列表里显示徽标和"下一次"日期；
- 显示位置：日程列表、月历标记、日视图底部叠加；与课程撞车会提示。

### 9.2 考试

「考试」标签 →「添加考试」：名称、日期、起止时间、教学楼/教室/座位号、类型（常规/期中/期末/补考/缓考）、重要程度（常规/重要）、备注。

- 列表自动倒计时（今天/明天/还有 N 天/已结束）；
- 考试前 30 分钟自动提醒；
- 与其他考试时间重叠时表单实时黄字警告；
- 与课程关联（可选字段）便于归类。

### 9.3 待办

底部输入框快速添加（可关联课程）；或「添加待办」打开完整表单（截止日期、优先级高/中/低）。

- 未完成按截止日排序，逾期标红置顶；
- 截止日早 8 点提醒、逾期每日轻提醒；
- 打勾完成（移到已完成区，可取消）；不需要的删除。

## 第十章 统计（「统计」页）

全部指标由本地课表实时计算，与课表所见一致（含调停补结果）：

- **总览四格**：课程数、学期总课时（节数）、教学进度百分比、剩余课次（自今天起）；

- **时段拆分**：上午 / 下午 / 晚间 / 早八数量；调课/停课/补课次数；
- **各课程教学时长**：横向条形排行（节数 + 周数）。

## 第十一章 导入与导出（「设置 → 数据」 + 课表页）

### 11.1 导入课程（四种来源）

入口：设置 → 数据 →「导入 CSV / XLSX」。向导分四步，支持两种来源：

**来源 A：文件（CSV / Excel）**
1. 选文件（第一行须为表头）；
2. **字段映射**：软件按表头自动匹配（课程名/教师/星期/节次/周次…），可手动改下拉；
3. **预览**：同名行合并为一门课的多个时间；无法解析的行显示原因（缺名称/星期/节次）；与现有课程**疑似重复**（同名同时间）会标记并可勾选跳过；时间冲突列出明细；
4. 确认导入，显示成功/跳过/失败数量，并记入**导入历史**（最近 20 次）。

**来源 B：粘贴文本 / 分享码**
- 每行一门课，格式如：`高等数学 周一 1-2节 1-8周 教一101`（支持"星期X""周5""1、3、5周"等写法；教室=含数字的词；教师写"教师：张三"）；
- 点「识别文本」本地解析（不上传）；
- 已在设置里配置 AI 的用户会多一个「AI 解析」按钮：用你自己的大模型解析任意格式课表，结果同样作为提案进入预览确认。

**来源 C：二维码 / 分享码**（他人分享）

**来源 D：JSON 备份**（见 11.3）。

### 11.2 导出

| 导出 | 位置 | 内容 |
| --- | --- | --- |
| JSON 完整备份 | 设置→数据 | 全部数据（学期/课程/安排/调课/考试/日程/提醒/设置），换机迁移用 |
| 加密备份 | 设置→数据 | 同上，AES-GCM 加密（设密码），文件名标注 |
| 课程 CSV | 设置→数据 | Excel 可开的课程清单（UTF-8 不乱码） |
| 课程 Excel | 设置→数据 | 同上 .xlsx 格式 |
| ICS 日历 | 设置→数据 | 整学期逐日展开（含调课结果），可导入系统日历 |
| 课表 PNG | 课表页 📷 | 当前周课表图片（Canvas 绘制，主题自适应），可选隐藏教室/教师（脱敏） |
| PDF | 课表页 🖨 | 打印对话框中"另存为 PDF"（打印样式已优化，隐藏导航等杂项） |
| 诊断信息 | 设置→关于 | 环境与数量统计 JSON，**不含课程内容**（求助排查用） |

### 11.3 备份与恢复

- **自动本地备份**：每 24 小时自动快照，本机保留最近 3 份；设置 → 数据 → 自动本地备份列表可一键恢复（覆盖式）；
- **手动恢复**：导入 JSON 备份时选「合并导入」（按 ID 合并，保留现有其他数据）或「覆盖导入」（清空后还原，需谨慎）；
- **加密备份导入**：选到加密文件会出现密码框，解密后同样进入合并/覆盖选择。

### 11.4 WebDAV 同步（可选联网功能）

设置 → 联网与 AI → WebDAV：

1. 填你自己的 WebDAV 服务器（如坚果云：https://dav.jianguoyun.com/dav/ 、账户、应用密码）、目录（默认 /campusflow）；
2. 「测试并保存」验证连通（凭据只存本机）；
3. **上传备份**：把当前全部数据推到远端；**下载并合并**：拉回远端备份合并进本机。
4. 「清除」删除本机保存的配置。

### 11.5 二维码 / 分享码

课表页「分享」→ 可选隐藏教室/教师 →「生成二维码」或「复制分享文本」。对方在 TA 的导入向导「粘贴文本/分享码」里粘贴即可导入（含精确周次规则）。本地生成，无服务器参与。

## 第十三章 数据安全与隐私（重要）

1. **一切数据在本机**：IndexedDB（浏览器内置数据库）。无账号、无统计、无上传；
2. **换浏览器/清浏览器数据 = 数据消失**：请使用备份（自动 + 手动）；
3. **备份三重保险**：自动本地快照（每 24h，留 3 份）+ 手动 JSON 导出 + 可选加密；
4. **AI 功能**：默认关闭。使用需自配 API Key（OpenAI 兼容）；Key 只存本机；AI 返回的课表是"提案"，必须经你预览确认才入库；备份文件中不包含 AI 配置；
5. **WebDAV**：凭据只存本机；备份文件中不包含 WebDAV 配置；
6. **清除全部数据**：设置 → 关于 → 清除全部本地数据（二次确认，重置后回到首次启动状态）。

## 第十六章 常见问题 FAQ

**Q1 提醒不响？** 检查授权（设置→通知→授权通知；地址栏 🔒→通知→允许）→ 静音时段是否覆盖 → 周末开关 → 该课程是否设了"不提醒"。网页版浏览器关闭后无法提醒；要可靠提醒用 Windows 安装版。

**Q2 课表会丢吗？** 只要不"清除浏览器数据"就一直都在。保险起见：开启自动备份（默认就有）+ 每月导出一次 JSON。

**Q3 换手机/电脑？** 旧设备导出 JSON（可加密）→ 传到新设备 → 导入 →「合并导入」。

**Q4 两台设备自动同步？** 默认不支持（无账号无服务器）。可用 WebDAV 手动同步。

**Q5 单双周怎么算？** 以你设定的教学周序号，不是日历周。

**Q6 老师说下次换教室？** 右键/长按课程卡 → 调课 → 改教室 → 保存。原时段出现"已调走"。

**Q7 删错了？** 8 秒撤销条；变更记录随时撤销；自动备份兜底。

**Q8 时间线和课表对不上？** 检查学期"第一周起始日期"是否与校历一致（这是所有周次计算的总开关）。

**Q9 能导入学校教务系统的课表吗？** 直接网页抓取不支持（各校系统结构不同，也不该绕过学校验证）。支持两条路：① 教务系统导出的 Excel/CSV 文件 → 导入向导（自动字段映射）；② 复制课表文本 → 粘贴识别 / AI 解析。

**Q10 打开白屏？** 启用 JavaScript；退出无痕模式（其可能禁用数据库）；换新版 Chrome/Edge。

**Q11 手机上没有安装包？** 安卓 APK 与 iOS 需要对应平台工具链构建（工程已就绪，见 docs/PACKAGING.md）；现阶段手机请使用网页/PWA，功能完整。

**Q12 想重新开始？** 设置 → 关于 → 清除全部本地数据（二次确认）。
