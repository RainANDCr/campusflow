# CampusFlow 使用说明（小白版）

> 手把手教程：从打开软件到把课表用起来。不需要任何计算机知识，跟着点就行。
> 术语看不懂？文末有「名词小词典」。遇到问题？直接跳到「常见问题 FAQ」。

---

## 一、先拿到 CampusFlow（三种方式任选）

### 方式 1：直接在浏览器里用（最简单，推荐先试这个）

1. 打开浏览器（手机或电脑都行），访问：
   **https://rainandcr.github.io/campusflow/**
2. 就这么简单，直接开始用了。数据保存在你自己的设备里。

> 💡 建议把网址收藏/加书签，方便下次打开。

### 方式 2：装到手机桌面（像 App 一样，可离线用）

**安卓手机（Chrome / Edge 浏览器）：**
1. 用浏览器打开上面的网址
2. 点浏览器右上角的「⋮」菜单
3. 找到「添加到主屏幕」或「安装应用」，点它
4. 桌面上会出现 CampusFlow 图标，以后点图标就能打开，没有网址栏，离线也能看课表

**iPhone（Safari 浏览器）：**
1. 用 Safari 打开上面的网址
2. 点底部中间的「分享」按钮（方框加向上箭头）
3. 往下滑，点「添加到主屏幕」→「添加」

### 方式 3：Windows 电脑安装包（提醒功能最可靠）

1. 打开发布页：**https://github.com/RainANDCr/campusflow/releases**
2. 在最新版本（v2.0.0）下方，点击 `CampusFlow_0.1.0_x64-setup.exe` 下载
3. 双击运行，如果 Windows 弹出蓝色警告（因为程序没有数字签名），点「更多信息」→「仍要运行」
4. 安装完成后，开始菜单和桌面就有 CampusFlow 了，还会出现在系统托盘（屏幕右下角）

> 💡 三种方式的数据各自独立保存在各自设备里。想在电脑和手机之间同步课表？看「第七章：备份与换机」。

## 二、第一次使用：三步把课表立起来

### 第 1 步：创建学期

1. 打开 CampusFlow，点底部（手机）或左侧（电脑）的 **「学期」**
2. 点右上角 **「创建学期」** 按钮
3. 填写四个信息：
   - **学期名称**：随便起，比如 `2026-2027学年第一学期`
   - **开学日期**：点输入框选日子，比如 9 月 1 日
   - **教学周数**：你们学校这学期上多少周课，一般是 16～20 周（培养方案或教务系统里有写）
   - **每周起始日**：不用管，默认「周一」就对了
4. 点 **「保存」**

> ✅ 你会看到学期卡片上显示「当前」「进行中」和第几周——不用你算，软件自动算。
> 「第一周起始日期」那一栏不用动：软件会自动把开学那周的周一作为第一周开头（比如 9 月 1 日周二开学，第一周就是 8 月 31 日周一开始的这一周）。特殊情况可以自己改。

### 第 2 步：添加课程

1. 点 **「课表」** 页签回到课表
2. 点右上角 **「添加课程」**（手机上是一个紫色 ➕ 按钮）
3. 填写：
   - **课程名称**：必填，比如 `高等数学`
   - **教师 / 教学楼 / 教室**：可以现在填，也可以以后补
   - **课程颜色**：选一个喜欢的颜色，课表上一眼认出它
   - **图标**：选一个 emoji（比如 📐），不选也行
4. 下面的 **「上课时间」** 是重点，一行就是一个上课时间：
   - **星期**：这门课周几上？选「周一」
   - **起始节次 / 结束节次**：第几节上到第几节？比如第 1 节到第 2 节。每个节次旁边显示了具体时间（如 第1节 08:00），对着你们学校的作息表选就行
   - **周次规则**：这门课哪几周上？最常用的是：
     - 「每周上课」——每一周都上
     - 「单周」——只在第 1、3、5、7…周上（教务系统写"单周"就选这个）
     - 「双周」——只在第 2、4、6、8…周上
     - 「连续区间」——比如只在第 1～8 周上，选它然后填 1 和 8
     - 「指定周次」——想点哪周点哪周，比如第 1、3、5、7 周
5. 一门课有多个上课时间？（比如周一又周三都有）点 **「添加时间」** 再加一行
6. 点 **「保存」** —— 回到课表，课程卡片已经出现在格子里了！

> ✨ 更快的办法：直接**点击课表上的空白格子**，会自动帮你填好星期和节次，只需要填课程名。

### 第 3 步：日常使用

打开软件就是本周课表。今天几号、第几周、今天有什么课、现在在上什么，全都自动显示。

## 三、看懂课表页面

打开「课表」页，从上到下是：

- **学期名 + 第几周**：自动计算，假期会显示「假期中」
- **学期进度条**：这学期已经过了百分之多少、距离结束还有几周
- **每日寄语**：每天换一句
- **下节课卡片**：显示正在进行或下一节课的名字、教室、倒计时，以及今天还剩几节课
- **明日预览**：明天有什么课
- **五个视图按钮**：周 / 日 / 月 / 轴 / 列（下面细讲）
- **一排小工具按钮**：变更记录、节假日调整、分享、课程管理、导出图片、打印、添加课程

### 五种看课表的方式

| 视图 | 按哪里 | 适合什么场景 |
| --- | --- | --- |
| **周** | 点「周」 | 最常用，一整周格子课表 |
| **日** | 点「日」 | 今天到底有哪些事，按节次列出来，还能看空闲时段 |
| **月** | 点「月」 | 看整月安排，有课的日子有小圆点，考试的日子有红色三角 |
| **轴** | 点「轴」 | 按真实时间排列，能看到每节课几点到几点、空档在哪 |
| **列** | 点「列」 | 按周折叠的精简列表，快速扫一眼这周有什么 |

### 切换周次

- 点 **‹ ›** 箭头：上一周 / 下一周
- 点 **「回到本周」**：一键回当前周
- 手机上：在课表上**左右滑动**即可翻周
- 电脑上：按键盘 **← →** 翻周，按 **T** 回本周
- 想直接跳到某一天？用「日期跳转」选择日期即可
- 点 **⛶ 全屏** 按钮：课表全屏显示，再点一次退出

### 颜色和样式的含义

- 🟦 **正常显示**：还没上的课
- 🟩 **带发光描边**：正在上的课（软件每半分钟自动刷新）
- 🩶 **变灰变淡**：已经下课的课
- 卡片上的 **「调」** 角标：这一节被调课了
- 卡片上的 **「补」** 角标：这一节是额外补的课
- 划线的卡片：这一节停课了

## 四、改课程：编辑、复制、调课、停课、补课

### 想改课程信息（名字、教室等）

电脑：**右键点击**课程卡片 → 「编辑课程」
手机：**长按**课程卡片 → 「编辑课程」
（或者点卡片打开详情页 → 「编辑」）

### 老师说"下次课换教室 / 换时间 / 换到周三"（只改那一次）

这叫**调课**，不会影响以后每周的安排：

1. 电脑：**右键**课程卡 → 「调课（本次）」；手机：**长按** → 「调课（本次）」
2. 在弹出的窗口里改：新日期、新节次、新教室、新教师（改至少一项）
3. 点「保存」

> ✅ 课表上：原来的位置会显示半透明「已调走」，新的位置出现带「调」角标的卡片。一切清清楚楚。

### 老师说"这周不上课了"（停课）

1. 右键 / 长按课程卡 → 「停课（本次）」→ 保存
2. 那一节会显示成划线样式。以后的周照常上。

### 老师说"周六来补一次课"（补课）

1. 点开这门课的卡片 → 详情页里点 **「补课」**
2. 选补课日期（哪天都行，包括假期）、节次、教室
3. 保存后那天会出现带「补」角标的课程

### 后悔了想撤销调课/停课？

1. 课表页点 **「课程变更记录」** 按钮（时钟图标）
2. 找到那条记录，点 **垃圾桶图标** 撤销——课表立刻恢复原样

> 误删了整门课？删除后屏幕底部会弹「已删除 X 门课程 · 撤销」，**8 秒内**点撤销就能找回。错过 8 秒？看第七章的自动备份。

### 删课程 / 复制课程 / 批量操作

- 点 **「课程管理」** 按钮（列表图标）：可以搜索课程、勾选多门课**批量换颜色**或**批量删除**（都会先确认）
- 课程详情页里有「复制」按钮：整门课连同上课时间复制一份（改改就是另一门课）

### 用标签整理课程

编辑课程时可以加标签（比如「必修」「考研」）。在课程管理里可以按标签筛选。

## 五、考试、日程、待办

点 **「日程」** 页签，有三个标签页：

### 考试

1. 点「添加考试」：填名称、日期、时间、教室、座位号
2. 列表里自动显示**倒计时**（还有 N 天 / 明天 / 今天）
3. 考试当天会**提前 30 分钟提醒**你
4. 可以标记类型（期中/期末/补考/缓考）和重要程度

### 日程（社团、活动、生日……）

1. 点「添加日程」：填标题、日期、时间
2. **重复**选项：社团每周例会选「每周」；生日选「每年」——以后每年自动出现
3. 日程会自动出现在：月历视图的标记里、日视图底部的「当日个人日程」里；如果和上课时间撞了，会标注「与课程时间重叠」

### 待办（作业、要带的东西）

1. 在输入框直接打字（比如 `带实验报告`），可关联到某门课，点「添加」
2. 可以设**优先级**（高/中/低）和**截止日期**
3. 过期没完成的会标红「已逾期」并置顶
4. 做完打勾 ✔；截止日当天早上 8 点会提醒你

## 六、提醒设置（重要！）

点 **「设置」** 页签 → **「通知」**：

### 第一步：授权

- 点 **「授权通知」** 按钮。浏览器会弹窗问你"是否允许通知"——点**允许**
- 如果之前不小心点了拒绝：Chrome 里点地址栏左边的锁图标 → 通知 → 改为「允许」，然后刷新页面

### 第二步：按需开关

| 开关 | 作用 |
| --- | --- |
| **全局上课提醒** | 每节课前提前几分钟提醒（5/10/15/30/60 自选） |
| **下课提醒** | 每节课结束时通知一声 |
| **今日第一节课摘要** | 第一节课前 1 小时，告诉你今天有几节课 |
| **周末课程提醒** | 周末有课要不要提醒（默认开） |
| **通知静音时段** | 比如设 23:00–07:00，这段时间的提醒顺延到 7 点 |

> 💡 想给某一门课单独设置？编辑那门课时，把「上课提醒」从"跟随全局"改成具体分钟数（或"不提醒"）。

### 诚实说明提醒的局限

- **网页版**：浏览器开着时提醒可靠；浏览器完全关掉后不保证（这是所有网页的技术限制）
- **Windows 安装版**：通知走系统，最可靠
- **考试提醒**：自动提前 30 分钟，无需设置
- **待办提醒**：截止日早 8 点 + 逾期每日提醒

## 七、备份与换机（数据安全，必读！）

> ⚠️ 你的所有数据只存在**你自己设备**的浏览器/应用里。清除浏览器数据 = 删除课表。请养成备份习惯。

### 自动备份（开了就有，不用管）

软件每天自动在本机存一份快照（保留最近 3 份）。在 **设置 → 数据 → 自动本地备份** 里可以一键恢复到某份快照。

### 手动备份（推荐每个月做一次）

1. **设置 → 数据 → 「导出 JSON 备份」**：会下载一个 `.json` 文件，把它存到网盘/发给自己
2. 想更安全？用 **「导出加密备份」**：设一个密码，导出的文件没有密码打不开

### 换手机 / 换电脑怎么迁移

1. 旧设备：导出 JSON 备份，把文件传到新设备（微信文件传输助手/网盘都行）
2. 新设备：打开 CampusFlow → 设置 → 数据 → 「导入 JSON 备份」→ 选文件
3. 选择 **「合并导入」**（按 ID 合并，安全）或 **「覆盖导入」**（清空后完整还原，选这个前想清楚）

### 和同学互相分享课表？

- 课表页点 **「分享」** 按钮 → 生成二维码（可选隐藏教室和教师）
- 同学扫码得到一串文本 → 在 TA 的 CampusFlow「导入课程 → 粘贴文本/分享码」里粘贴 → 一键导入你的课表（含周次规则）
- 全程本地完成，不经过任何服务器

## 八、导入课表（不想手动录入？）

**设置 → 数据 → 「导入 CSV / XLSX」**，两种方式：

### 方式 1：导入文件

1. 选一个 CSV 或 Excel 文件（第一行要是表头）
2. 软件自动猜每个列是什么（课程名/星期/节次…），猜错了可以手动改
3. 检查预览：哪些课程会被导入、有哪些时间冲突、哪些和现有课程重复
4. 点「导入」

### 方式 2：粘贴文本（最快）

点「粘贴文本」，把课表文字粘进去（从群公告、网页复制都行），点「识别文本」：

```text
高等数学 周一 1-2节 1-8周 教一101
大学英语 周三 3-4 单周 文B-202
```

软件自动认出课程名、星期、节次、周次、教室，确认后一键导入。

### 导出给你自己留底

设置 → 数据 里可以导出：课程清单 **CSV**、**Excel**、整学期日历 **ICS**（导入手机系统日历用）。

## 十一、常见问题 FAQ

**Q1：提醒不响？**
① 检查是否点了「授权通知」（设置→通知）；② 浏览器地址栏左边的锁图标 → 通知是否为"允许"；③ 是否设了静音时段；④ 是否关了周末提醒；⑤ 网页版在浏览器完全关闭后无法提醒——想可靠提醒请用 Windows 安装版。

**Q2：换手机/重装系统，课表会丢吗？**
浏览器数据里的课表在"清除浏览器数据"后会丢。请提前「导出 JSON 备份」；就算忘了，本机的自动备份（最近 3 份）可能还能救回来（设置→数据→自动本地备份→恢复）。

**Q3：两台设备能自动同步吗？**
默认不能（数据只在本地）。两条路：① 手动导出/导入 JSON 备份；② 设置→联网与 AI 里配置你自己的 WebDAV（比如坚果云）后手动上传/下载合并。

**Q4：单双周到底怎么算的？**
以你创建学期时的"教学周"为准，不是日历周。第一周 = 开学那周。第 1、3、5…周叫单周，第 2、4、6…周叫双周。切换周次时课表自动只显示该周的课。

**Q5：老师中途说换教室，我该编辑课程还是调课？**
只影响一次 → 用「调课」（长按/右键课程卡）；以后每周都换 → 用「编辑课程」改教室。

**Q6：点错删了东西怎么办？**
删除后有 8 秒撤销条；调课/停课在「变更记录」里随时撤销；最坏情况用自动备份恢复。

**Q7：我的数据会被上传吗？**
不会。没有账号、没有服务器，一切在你设备里。只有当你主动配置了 AI（用自己的 API Key）或 WebDAV（用自己的服务器）时，才会按你的操作与那些服务交互。

**Q8：打开是空白/白屏？**
① 确认没有禁用 JavaScript；② 无痕/隐私模式下部分浏览器禁用 IndexedDB，请用正常模式；③ 换 Chrome/Edge 新版本试试。

**Q9：手机上怎么删除？**
PWA：直接删除主屏图标 + 清除浏览器站点数据；Windows：设置 → 应用 → 卸载。想清空数据重新开始：设置 → 关于 → 清除全部本地数据（会二次确认）。

**Q10：我们学校的作息和默认不一样？**
学期页 → 编辑学期 → 节次时间里自由增删改每一节的时间；也可以直接「套用作息模板」（常规 12 节 / 紧凑 8 节 / 含晚自习 14 节）再微调。甚至可以给某一天单独设作息（比如周四只有 6 节）。

## 十二、名词小词典

| 词 | 意思 |
| --- | --- |
| **教学周** | 从第一周开始按周数的编号（第 1 周、第 2 周……），按你设定的开学日推算，和日历上的"第几周"无关 |
| **单周 / 双周** | 教学周序号是奇数/偶数的那些周。高数单周上、英语双周上，就是错开上课 |
| **节次** | 一天里按时间划分的上课单元（第 1 节、第 2 节……），每节的时间在学期设置里自定义 |
| **调课** | 某一次课换了时间/地点/教师，只影响那一次 |
| **补课** | 在正常安排之外额外加的一次课 |
| **例外 / 变更记录** | 所有调停补的流水账，删除一条 = 撤销这次变更 |
| **课表方案** | 同一学期的多套课表（比如"正式课表"和"试听课表"），互不干扰，随时切换 |
| **PWA** | 渐进式 Web 应用：在浏览器里点"安装"后像普通 App 一样有图标、可离线 |
| **IndexedDB** | 浏览器内置的本地数据库，你的数据就存在这里，不上网也能用 |
