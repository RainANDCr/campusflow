# CampusFlow 使用说明

## 快速上手（3 步）

1. **创建学期**：底部导航 →「学期」→ 创建学期。填写名称、开学日期、教学周数；第一周起始日会按开学日期自动推算（如周二开学则默认该周周一），可手动微调。节次时间默认为常见大学作息（12 节），可自由增删改。
2. **添加课程**：回到「课表」页，点「添加课程」（或直接点击课表空白格，会预填星期与节次）。填写名称，添加一个或多个上课时间（星期 + 起止节次 + 周次规则 + 可覆盖教室/教师），保存。
3. **看课表**：首页即当前教学周的课表。左右按钮 / 键盘 ←→ / 手机左右滑动切换周次；「回到本周」（快捷键 T）一键返回。今天列会高亮，正在上的课有强调色描边，已结束的课自动变灰。

## 核心概念

### 教学周与单双周
- 所有周次按**你设定的教学周序号**计算（第 1 周 = 第一周起始日所在周），与日历周无关。
- 周次规则支持：每周 / 单周 / 双周 / 连续区间（如 1-8 周）/ 指定任意周（如 1、3、5、7）。
- 切换教学周时课表自动切换为该周实际课程；开学前与学期结束后显示“假期中”。

### 调课 / 停课 / 补课
在课程详情（点击课表卡片）中操作：
- **调课**：改某一天的日期/节次/教室/教师——原时段会显示“已调走”占位，新位置带“调”角标；
- **停课**：某一天不上，卡片显示划除；
- **补课**：在重复规则之外加一次课（假期日期也可以）。
所有变更都记录在课表页右上角的「课程变更记录」中，删除记录即完全恢复原状，原始重复规则永不修改。

### 提醒
- 设置 → 通知：授权系统通知、设置全局提前量（5/10/15/30/60 分钟）；
- 单门课程可在课程表单中覆盖全局设置（含“不提醒”）；
- 考试自动提前 30 分钟提醒；
- 平台差异：浏览器/PWA 在应用打开期间可靠提醒；Windows 桌面版走系统通知；Android/iOS 为原生本地通知。提醒状态受平台限制，浏览器关闭后不保证触发。

### 日程与考试
- 「日程」页三个标签：考试（自动倒计时）、日程（个人/活动/重要日期）、待办（可关联课程，勾选完成）。
- 课表页顶部有“下节课倒计时”卡片（可在设置中关闭）。

## 数据管理（设置 → 数据）

| 操作 | 说明 |
| --- | --- |
| 导出 JSON 备份 | 完整备份（学期/课程/调课/日程/考试/设置），换设备手动迁移用 |
| 导入 JSON 备份 | 「合并」= 按 ID 覆盖写入；「覆盖」= 清空后还原（不可撤销） |
| 导出课程 CSV | Excel 可打开的课程清单（UTF-8 BOM，不乱码） |
| 导入 CSV / XLSX | 四步向导：选文件 → 字段映射（自动识别常见表头）→ 预览与冲突检测 → 确认导入 |
| 导出 ICS | 整学期逐日展开的日历文件（含调课结果），可导入系统日历 |
| 导出 PNG / PDF | 课表页右上角：当前周课表图片；打印对话框中选“另存为 PDF” |

导入的周次文本支持：“全部 / 每周 / 单周 / 双周 / 1-8周 / 1、3、5周” 等常见写法；星期支持 “周一 / 星期一 / Mon / 1”。所有解析与导入都在本地完成，文件不会上传。

## 外观（设置 → 外观）

- 6 主题 × 浅色 / 深色 / 跟随系统，即时切换；
- 8 种强调色；
- 「轻二次元装饰」：浅色模式漂浮花瓣、深色模式闪烁星空，随时可关。

## 桌面快捷键

| 按键 | 功能 |
| --- | --- |
| ← / → | 上一周 / 下一周 |
| T | 回到本周 |

## 数据安全

所有数据只保存在本机（IndexedDB）。应用不请求账号、不上传任何数据；云同步未实现，跨设备请使用 JSON 备份文件。清除浏览器数据会删除课表，请定期导出备份。
